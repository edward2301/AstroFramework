When a model is discontinued, the question is not what is new but what still fits.

## Start from the constraints
List the mounting thread, the output signal and the accuracy class of the existing unit. These three usually decide whether a drop-in replacement exists.

## Use the replacement note
Each discontinued model page lists the recommended replacement path. Follow it before considering a bracket change.

## When a change is unavoidable
A thread adapter is usually cheaper than a reweld. An output change may only need a control-input reconfiguration.

## Document the swap
Record the old code, the new code and the installation date, so the next replacement starts from that record.
